# User Stories

## User Story 1: Receive Suitable Workout Recommendations

**As a** beginner fitness user

**I want** to provide my fitness goals, available equipment, and workout preferences

**So that** I can receive a workout routine that matches my needs.

### Acceptance Criteria

- User can enter fitness preferences.
- User can save profile information.
- System generates workout recommendations.
- Recommendations include exercises, sets, repetitions, and rest periods.

---

## User Story 2: Record Completed Workouts

**As a** gym enthusiast

**I want** to record completed workout sessions

**So that** I can track my fitness activities and performance.

### Acceptance Criteria

- User can view recommended workouts.
- User can record completed workout sessions.
- System stores workout history.
- User can review past workout records.

---

## User Story 3: Monitor Workout Progress

**As a** fitness user

**I want** to review my workout history

**So that** I can understand my progress and consistency over time.

### Acceptance Criteria

- System displays completed workout history.
- System summarizes user progress.
- New workout records update the user history.
- Users can compare previous records.
